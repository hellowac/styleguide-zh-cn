1 背景 
======================

1 Background 

.. tab:: 中文

    Python 是 Google 的主要动态语言。本代码风格指南列出了 Python 程序的“注意事项”。

    为了帮助您正确设置代码格式，我们创建了一个 `Vim 设置文件 <https://google.github.io/styleguide/google_python_style.vim>`_ 。对于 Emacs，默认设置即可。



    许多团队使用 `Black <https://github.com/psf/black>`_ 或 `Pyink <https://github.com/google/pyink>`_ 自动格式化程序来避免格式​​方面的争论。

.. tab:: 英文

    Python is the main dynamic language used at Google. This style guide is a list of *dos and don'ts* for Python programs.

    To help you format code correctly, we've created a `settings file for Vim <https://google.github.io/styleguide/google_python_style.vim>`_ . For Emacs, the default settings should be fine.

    Many teams use the `Black <https://github.com/psf/black>`_ or `Pyink <https://github.com/google/pyink>`_ auto-formatter to avoid arguing over formatting.
